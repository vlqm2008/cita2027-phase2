# TASK-005A: causal calibration specification (v1, exploratory hyperparameters)

**Scope.** Frozen TSFM q10/q50/q90 on audited SPY daily **decimal log-return** forecasts. Full raw cache remains immutable. Forecast origin row index `i` predicts realized return `y_i = log_return[i+1]`, observed at the next exchange session. Information set at origin `i`: returns through row `i`, past settled forecast residuals and scores, previously committed model quantiles; **not** `log_return[i+1]`. Initial 256 context observations through origin 3272 are allowed. Initial forecast origin 3272 (2018-01-02). All records and their dates/hashes are re-validated with TASK-004B.2 `verify_complete` before calibrating.

**Nominal coverage.** The native 0.10/0.90 quantiles define exploratory central **80%** coverage, so target miscoverage `a=0.20`. A 90% experiment would need separately specified quantile inputs (do **not** call existing q10/q90 a 90% target). For each model and origin `i`, native lower/upper `(L_i,U_i)=(q10_i,q90_i)` are fixed. Signed CQR score `e_i=max(L_i-y_i, y_i-U_i)` can be negative if y_i is strictly within raw interval. Signed score is **not** `max(0,e_i)`.

**Order statistic.** For a buffer of `n=252` preceding (already settled) normalized scores `z`, sort nondecreasing. At effective alpha `a_i`, let `k=ceil((n+1)(1-a_i))`. Define `Q_i=z_(k)` (1-indexed) for `k<=n`; for `k=n+1`, `Q_i=+infinity`. No linear interpolation and no randomized tie breaking; duplicates stay and equality with either endpoint is covered. This is the conformal rank convention, NOT NumPy's linear quantile for the **TSFM samples**. In time series, this rank alone provides no distribution-free coverage guarantee.

**Endpoint rule.** `C_i=[L_i - d_i, U_i + d_i]`, with `d_i=s_i max(0,Q_i)` in main **expansion-only** 3x3. This uses signed scores but clamps the correction, not the scores. It cannot contract raw intervals and is a modified, conservative variant of ordinary signed CQR. Separate signed CQR ablation uses `d_i=s_i Q_i`, allowing contraction; when endpoints invert, the conformal set is empty and ordinary finite-interval Winkler scoring is **undefined**, so code rejects rather than silently swapping endpoints. The primary 3x3 is expansion-only, with the signed-only ablation separately planned. Scores have units decimal log return for `none`, dimensionless when divided by a positive volatility scale.

**Scales at origin.** Set `epsilon=1e-6` decimal log return. Let `v^ret_0=v^res_0=max(mean(r^2) over first origin's 256 causal returns,epsilon^2)`, available at first origin. The reference `s_ref=max(sqrt(v^ret_0),epsilon)` is fixed for the stream. At origin `i`, use `s_i=1` for `none`, `max(sqrt(v^res_i),epsilon)` for residual EWMA, `max(sqrt(v^ret_i),epsilon)` for return EWMA. After *the target of origin i* is observed at the next session, and only then: `v^ret_{i+1}=lambda*v^ret_i+(1-lambda)*y_i^2`, `v^res_{i+1}=lambda*v^res_i+(1-lambda)*(y_i-q50_i)^2`, lambda `0.94`. Store standardized score `z_i=e_i/s_i` using the origin-time scale. No future realized volatility or future residual enters the current score buffer.

**Shared gamma driver.** Independently of which score scaling condition is chosen, `h_i=clip(s^ret_i/s_ref, 0.5, 2.0)`, using the same deterministic return-EWMA recursion in all nine cells. In fixed ACI `gamma_i=gamma0=0.01`; variable ACI `gamma_i=gamma0*h_i`; rolling CQR gamma is unused. The driver is the **same for all scaling variants**; this avoids confounding the interaction, although normalizing by a fixed reference remains an experimental design choice rather than an established theoretical result.

**ACI state and timing.** During first `W=252` origins, collect 252 settled scores but produce no evaluated intervals and **do not update alpha**. At first evaluated origin (index `3272+252=3524`), initialize `a_i=a=0.20`. At origin i: build interval with previous W scores and the current `a_i`, then observe target, record miss `m_i=1[y_i<Lcal_i or y_i>Ucal_i]`, then set `a_{i+1}=clip(a_i + gamma_i*(a-m_i), 1/(W+1), 1-1/(W+1))`. Miss lowers the next alpha (wider interval); hit raises alpha. The clipping is an **explicit modification of original ACI** made to keep rank thresholds finite, and it does not inherit unmodified ACI's theoretical guarantees. For rolling CQR, use fixed `a` each origin. The calibration buffer advances after prediction/observation in all cells.

**One-step temporal protocol.** First 252 development forecast pairs are calibration-only burn-in. For the complete existing 1258-pair development cache, eligible evaluation range contains **1006** origins (not evaluated here). TASK-005A uses only the **first 320** development origins: 252 for calibration and **68** for a technical pilot; no tuning, optimization, or valid model ranking is performed. Example values W252, lambda0.94, gamma0.01, driver caps 0.5–2, epsilon1e-6 are **illustrative pre-registered pilot constants**, not yet empirically selected hyperparameters. TASK-005B must define a chronological development-only tuning split/budget before searching these values; freeze choices prior to any validation evaluation. Validation and final-test caches are neither present nor read in TASK-005A. Never tune on final test. Warm-start or reset policy on validation must be locked before generating its forecasts.

**Metrics.** For each evaluated origin with valid `l<=u`: `Winkler_i=(u-l)+(2/a)*(l-y)*1[y<l]+(2/a)*(y-u)*1[y>u]`. Decompose average width, lower and upper penalties separately. Marginal empirical coverage: mean indicator `l<=y<=u`; lower/upper tail miss rates: mean `y<l`, mean `y>u`. Rolling empirical coverage is windowed descriptive performance only, **not conditional coverage**. The pilot also shows empirical coverage by an **ex-ante return-volatility stratum** using the first-origin context RMS as a fixed split threshold, explicitly labelled proxy; no distribution-free conditional-coverage claim. Actual conditional coverage is unknown. Compare only on identical origin sets for 18 cells (9 per backbone).

**Scientific constraints.** Keep `contamination_free_verified=false`, `point_in_time_adjusted_prices_verified=false`, `scientific_clearance=false`. No claimed conformal finite-sample/ACI finite-time guarantees for dependent returns and modified clipping/scales. Do not infer volatility clustering adaptations imply trading gains. Calibration outputs are new immutable JSON under `artifacts/calibration/task005a/<accepted_plan_sha>/`; native forecast records, plan, manifests, splits, and checkpoints are never mutated.

Gibbs & Candès, *Adaptive Conformal Inference Under Distribution Shift*, NeurIPS 2021 (update `a_next=a+gamma*(target_a-miss)`).
